# Reconstruction documents: canonical planning entrypoint

The cross-discipline, full-game production and release plan lives in **[docs/MASTER_PLAN.md](../../docs/MASTER_PLAN.md)**. It is the canonical production charter and defines player promises, AAA-quality delivery gates, ownership, testing, original-IP constraints, launch criteria, and the critical path.

The existing **[full-game waterfall](full-game-waterfall.md)** remains the detailed W0–W8 system backlog and historical evidence narrative. **[Player-scale design evidence](player-scale-design-evidence.md)** records original research, assumptions, and metric limitations.

For extraction coverage and present claims, use the current **[machine ledger](../data/extraction_coverage.json)**, exact GitHub branch/commit, linked original-binary Actions artifacts, and **[control issue #32](https://github.com/Nippytime/rabron/issues/32)**. A proposed PR's measured coverage is not integrated `dev` coverage until the PR is merged and postmerge checks are verified.

A planning document or green headless test does **not** establish shipped gameplay, recovered authoritative formulas, rights to third-party media, real Unity Play Mode execution, or a tested Windows executable. Those require separately recorded evidence and human acceptance.
